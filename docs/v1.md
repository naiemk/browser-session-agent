# Browser Operations Agent — V1

## Outcome
Evolve the MVP into a controlled multi-agent browser operations system. A supervisor creates a live work graph, assigns focused browser subagents, and aggregates evidence-backed outcomes.

## Capabilities
- supervisor and work-item graph
- tab ownership and bounded parallel subagents
- shared Human Session queue
- profile, document, evidence, recovery, and knowledge harnesses
- email-verification dependencies
- candidate knowledge evaluated before promotion

## Learning
Pi improves operational behavior through observed evidence, reusable strategies, and user-approved knowledge. It never silently alters product code or broadens authority.

## Exit criteria
Multiple work items can run, pause on shared dependencies, resume after human help, and return an aggregate result.
