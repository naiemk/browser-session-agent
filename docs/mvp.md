# Browser Operations Agent — MVP

## Goal
Prove a local, Pi-powered browser operator: a CLI goal can drive one visible persistent Chromium profile through bounded Playwright tools, pause for the user, then resume from observed browser state.

## Included
- Pi CLI extension with browser-operation tools
- local browser worker and Playwright
- one persistent headed Chromium profile
- inspect, navigate, click, type, select, scroll, wait
- action verification plus screenshots and evidence log
- targeted CLI clarification, human takeover, pause and resume
- candidate knowledge records for approved answers and successful strategies

## Excluded
- multi-agent orchestration
- web dashboard
- broad email integration
- unrestricted scripting or self-modifying code

## Success
A user starts a browser goal, completes a required login in the visible tab, and Pi safely resumes and completes a bounded browser task.
