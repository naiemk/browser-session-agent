# Epic: V1 Hosted Agent and Helper

Status: done (100% — all 24 tasks have implementations and passing E2Es)

## Outcome

A non-developer can create an account, install a Windows/Mac helper with two clicks, see **Connected** without typing a token, start a goal in the hosted chat, and let the agent inspect and act on a dedicated Playwright Chromium on their machine. Login/CAPTCHA uses takeover and live view. Quitting the helper fails browser tools closed with a clear message. They pay for the hosted agent.

This is the product boundary in `docs/v1.md`. Docker and the Pi CLI remain power-user paths.

## Risks

- pairing must never require pasting `BSA_TOKEN` or baking a secret into the installer
- the hosted API must not run Chromium
- one LLM call per click is too slow; harness + page plans must stay the source of truth
- Windows/Mac signed installers cannot be the CI gate (Linux proves protocol + helper binary + manifests)

## Stories

- V1-01: Hosted account and chat
- V1-02: Pair this computer
- V1-03: Drive my browser from chat
- V1-04: Live view and takeover
- V1-05: Honest action harness
